# Как читать проект с нуля

Начните с PDF или docs/development-guide.md. Там объясняются слова и конструкции, которые встречаются ниже. Все пути к коду здесь указаны от src/HelpDesk.Api, если не сказано иначе.

## Первый проход: понять задачу

1. Прочитайте главы 1-3 учебника. Найдите корень проекта, приложение и тесты.
2. Разберите основы C# в главе 4: переменная, условие, свойство, метод.
3. Откройте Domain/Ticket.cs и прочитайте только Reopen. Перескажите каждую строку.
4. По главам 5-6 отправьте запрос в Swagger. Сохраните id и version.

Проверка: можете ли вы объяснить разницу между клиентом, API и базой? Если нет, вернитесь к главе 2.

## Второй проход: одна заявка

1. Controllers/TicketsController.cs, Create: где принимается запрос?
2. Application/Contracts.cs, CreateTicketRequest: какие поля разрешены?
3. Application/TicketService.cs, CreateAsync: какие действия идут по порядку?
4. Domain/Ticket.cs, Create и Edit: какие данные запрещены?
5. Infrastructure/EfTicketStore.cs, SaveAsync: где происходит сохранение?

Ответ для самопроверки: контроллер принимает, сервис организует, сущность проверяет, хранилище сохраняет. Не нужно читать все методы файла сразу.

## Третий проход: доступ и ошибки

1. EfTicketStore.Visible: найдите сравнение владельца с текущим пользователем.
2. TicketService.CommentsAsync: найдите проверку заявки до чтения комментариев.
3. Ticket.Close: кто может закрыть заявку?
4. TicketService.CheckVersion: почему старая версия отклоняется?
5. ApiExceptionHandler: найдите превращение ошибки в 404 или 409.

Проверка: объясните 401 без токена, 403 обычному пользователю на take и 404 на чужой id. Объясните, почему комментарий меняет version.

## Четвёртый проход: тесты и устройство запуска

В tests/HelpDesk.Api.Tests/TicketTests.cs прочитайте один тест: создание данных, действие, Assert. Затем в ApiTests.cs найдите OtherUsersTicket_IsHiddenOnEveryAccessibleRoute. Прочитайте его варианты InlineData.

После этого переходите к HelpDeskDbContext, Program.cs и compose.yaml. Сначала ищите знакомые имена TicketService, Identity и SQL Server. Сгенерированные Designer, ModelSnapshot, bin и obj пока пропустите.

## Первое упражнение

Добавьте тест: для Open вызов Reopen должен выдавать RuleException. Используйте соседний Assert.Throws как пример. До запуска предскажите результат. Затем соберите проект и выполните тесты по README.

Более сложный прежний маршрут сохранён в reading-map-advanced.md. Он нужен после этого прохода.
