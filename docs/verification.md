
Проверены: правила сущности; регистрация, вход и refresh через настоящий Identity; ошибки входных данных; подмена ownerId/status и попытка самовыдачи роли; доступ к чужой заявке через все доступные обычному пользователю объектные маршруты; роли и назначенный исполнитель; полный цикл заявки; закрытая заявка; версия клиента и два писателя на уровне EF; фильтрация, сортировка и страницы; UTC; повторный seed; блокировка входа и rate limit; готовность приложения и описание API.

## Что в этой среде не выполнялось

- **SQL Server и LocalDB не установлены.** Сформирована и проверена модель миграции, но её выполнение на настоящем SQL Server здесь не происходило.
- **Docker CLI/Desktop отсутствует.** Docker image, Compose и внешний Smoke.ps1 здесь не запускались против настоящего контейнерного окружения.
- **GitHub Actions не запускался.** Файл workflow подготовлен; публикация репозитория не выполнялась. Второй job повторяет тесты на настоящем SQL Server и применяет миграцию в новых временных базах.

Для завершения проверки именно контейнерного окружения на машине с Docker выполните команды быстрого запуска README и scripts/Smoke.ps1. Для SQL-проверки без Compose можно задать HELPDESK_TEST_SQLSERVER и выполнить те же тесты. Не смешивайте результаты SQLite с подтверждением особенностей SQL Server.

## Технические замечания

Явная зависимость System.Security.Cryptography.Pkcs 10.0.14 устраняет уязвимую транзитивную 9.0.11, обнаруженную NuGet при первой сборке. Предупреждения не подавлялись. Пакеты следует периодически обновлять и перепроверять; эти результаты относятся к зафиксированному состоянию проекта.

Количество 41 включает случаи Theory с разными InlineData. Это не заявленный процент покрытия: инструмент измерения покрытия не запускался.
